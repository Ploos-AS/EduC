# Curriculum contract

EduC owns the portable C foundation used by sibling courses.

## EduC guarantees

A graduate should understand functions, translation units, arrays, pointers, strings, structs/unions/enums, dynamic allocation, streams, error handling, object lifetime, undefined behavior, testing and debugging fundamentals.

## Boundary

EduC may mention operating systems for context, but does not teach POSIX or AmigaOS APIs as core C. Those topics belong in EduPOSIX and EduAmigaC.
