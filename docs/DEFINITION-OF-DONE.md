# Definition of done

A course chapter is complete only when applicable items below are true:

- learning objectives are explicit
- terminology is introduced before use
- code listings are complete and understandable
- repository examples compile with the supported warning policy
- executable examples are exercised by automated checks where practical
- exercises and checkpoint exist
- unsafe/undefined examples are clearly labelled
- platform dependencies are identified
- publishing output has been checked
- links and cross-references are valid

A milestone requires all included chapters to satisfy this definition, not merely to exist as files.
