# EduC syllabus

## Part I — Foundations
1. Your first C program
2. Compiler, preprocessor and linker
3. Types, values and expressions
4. Decisions and loops
5. Functions, scope and storage duration

## Part II — Data and memory
6. Arrays
7. Strings
8. Pointers
9. Structs, enums and unions
10. Dynamic memory

## Part III — Building programs
11. Streams and files
12. Translation units and headers
13. Interfaces and small libraries
14. Error handling
15. The C abstract machine and undefined behavior

## Part IV — Professional C
16. Defensive and secure C
17. Debugging
18. Testing and static/dynamic analysis
19. Portability and generated assembly
20. Capstone projects

Each chapter should end with exercises and at least one executable checkpoint where appropriate.
