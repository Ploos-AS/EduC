# EduC Roadmap

## M0 — Foundation

- define scope and prerequisites
- establish curriculum
- establish repository layout
- add licensing
- add first portable C example
- document relationship to EduPOSIX and EduAmigaC

## M1 — C fundamentals

- toolchain and first program
- types, expressions and control flow
- functions and scope
- exercises and tests

## M2 — Data and memory

- arrays and strings
- pointers
- structs, enums and unions
- dynamic memory

## M3 — Real programs

- files and streams
- multi-file projects
- libraries and interfaces
- build tooling

## M4 — Correctness

- undefined behavior
- diagnostics
- debugging
- testing
- sanitizers where available

## M5 — Systems awareness

- memory model
- ABI concepts
- reading generated assembly
- portability

## M6 — Secure C

- defensive parsing
- integer and buffer errors
- ownership conventions
- safer APIs and review techniques

## M7 — Capstones and publishing

- complete projects
- bilingual course material
- web/book publishing integration
