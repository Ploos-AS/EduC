# 01 — Your first C program

## Learning objectives

After this chapter you can explain the basic shape of a C program, compile it, run it, and distinguish source code from the resulting executable.

## Concepts

- source files and executables
- `main`
- statements and blocks
- `#include`
- `printf`
- return status
- compile → link → run

## Lab

Build and run `examples/hello/hello.c` using the repository Makefile.

## Checkpoint

Explain what the compiler does, what the linker does, and why `return 0;` is not printed on screen.

## Exercises

1. Change the greeting.
2. Print two lines.
3. Introduce a syntax error, read the diagnostic, then fix it.
4. Inspect the program's exit status.
