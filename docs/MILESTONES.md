# Milestones

- **M0 — Foundation:** scope, licensing, structure, CI, publishing contract, syllabus and seed example.
- **M1 — C foundations:** chapters 1–5 with exercises and tested examples.
- **M2 — Data and memory:** arrays, strings, pointers, aggregates and allocation.
- **M3 — Program construction:** files, translation units, interfaces and errors.
- **M4 — Correctness:** language hazards, defensive C, debugging and testing.
- **M5 — Portability and machine connection:** standards, ABI/assembly literacy.
- **M6 — Complete course:** capstones, review, bilingual/publishing qualification.
