# EduC course source

This directory is the canonical course/book source.

## Learning path

The learner starts with no C knowledge. Each module should contain theory, a small complete example, exercises and a short checkpoint.

## Module groups

- 01–05: foundations — toolchain, values, control flow, functions
- 06–10: arrays, strings, pointers, aggregates, dynamic memory, streams
- 11–15: program structure, interfaces, memory model, language hazards, secure C
- 16–20: debugging, testing, portability, assembly connection, capstones

EduC deliberately avoids teaching POSIX or AmigaOS APIs as if they were part of C.
