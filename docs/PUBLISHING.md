# Publishing contract

The canonical educational source lives in `course/`.

Planned outputs:

- web/HTML
- PDF/book
- EPUB when supported by the shared Ploos publishing toolchain
- Norwegian edition generated from maintained translated source, not machine-translated at release time without review

Generated output belongs in `build/` or `dist/` and is not canonical source.

The repository should integrate with the shared Ploos-AS/publishing workflow rather than grow a separate publishing stack.
